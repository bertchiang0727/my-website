Bipedal Walking Control Using Model Predictive Control (MPC)

This project investigates bipedal walking control using the Linear Inverted Pendulum Model (LIPM) and Model Predictive Control (MPC). The objective is to develop a simulation framework for predicting center-of-mass motion and adapting future footstep locations in response to external disturbances. By combining simplified robot dynamics with predictive optimization, the project explores how footstep adjustment can contribute to balance recovery during dynamic walking.

Dynamic Modeling - LIPM

The Linear Inverted Pendulum Model (LIPM) is used to approximate the dynamics of bipedal walking. By assuming a constant center-of-mass (CoM) height and neglecting angular momentum variations, the complex dynamics of a humanoid robot can be simplified into a linear model. The horizontal CoM motion is described by the following equation:

ẍ = (g / zc)(x - p)

Here, x represents the horizontal CoM position, zc is the constant CoM height, g is gravitational acceleration, and p is the Zero Moment Point (ZMP). This simplified model provides the foundation for predicting future CoM trajectories and formulating the walking control problem.

Model Predictive Control Design

Model Predictive Control (MPC) is applied to predict future robot motion over a finite prediction horizon. At each control step, an optimization problem is formulated using the system dynamics, desired walking trajectory, and balance-related constraints. The controller evaluates predicted motion and determines control actions that improve trajectory tracking while considering future walking behavior. The optimization is repeatedly updated as new system states become available, allowing the controller to respond to changes during walking.

External Disturbance Simulation

To investigate the robustness of the walking controller, an external disturbance is introduced during the simulated walking process. The disturbance affects the robot's center-of-mass motion and causes deviations from the nominal walking trajectory. The resulting motion is analyzed to understand how external forces influence balance and how predictive control can support disturbance recovery.

Adaptive Footstep Planning

Adaptive footstep planning is investigated as a balance recovery strategy for bipedal walking. Instead of relying exclusively on predefined footstep locations, the walking control framework considers adjustments to future foot placement based on the predicted motion of the robot. Following an external disturbance, modifying the upcoming footstep locations can help compensate for changes in center-of-mass position and velocity. This approach highlights the relationship between predictive control, dynamic stability, and footstep planning.

Simulation Results

Python-based numerical simulations are used to investigate center-of-mass trajectories, disturbance responses, and adaptive footstep planning. The analysis focuses on the relationship between the predicted CoM motion, footstep locations, and the robot's response to external disturbances. Simulation plots can be used to compare nominal walking behavior with disturbance-affected motion and evaluate the effect of footstep adaptation.
